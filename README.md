## 🚀 Projects

### [visual-json-mapper](https://github.com/godwire/visual-json-mapper) — embeddable visual data mapper

Connect two JSON structures by drawing lines; the result is an executable, versioned
mapping document rather than a picture. Framework-independent TypeScript core —
expression tree, dependency graph with cycle detection, scope-aware iteration over
nested arrays, ~50 transformations, four-level validation, TypeScript code generation —
with a Vue 3 UI on top. 112 unit tests, Playwright e2e, full CI, MIT.
